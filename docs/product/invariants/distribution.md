# Invariant register — Distribution and conduct

[Invariant register](../invariants.md) · [Spice product model](../README.md)
## Distribution

| Label | Invariant |
| --- | --- |
| <a id="distribution-release-notes-derive-from-history"></a>**Release notes derive from history** | Release notes derive from history; there is no maintained changelog to drift. |
| <a id="distribution-implement-and-revert-pairs-in-one-range-are-suppressed"></a>**Implement-and-revert pairs in one range are suppressed** | Implement-and-revert pairs in one range are suppressed; phase pairs dedupe by task. |
| <a id="distribution-the-release-gate-runs-the-full-battery"></a>**The release gate runs the full battery** | The release gate runs the full battery, broader than the commit gate, and skipped coverage is resolved rather than accepted as a pass. |
| <a id="distribution-inspection-is-free-of-consequence"></a>**Inspection is free of consequence** | Inspection is free of consequence: checking the gates, drafting the notes, and previewing the range never bump, commit, tag, push, or publish. |
| <a id="distribution-an-install-records-what-it-did"></a>**An install records what it did** | An install records what it did so an unapply removes exactly that. |
| <a id="distribution-every-verb-that-can-change-anything-renders-its-complete-ordered-plan"></a>**Every verb that can change anything renders its complete ordered plan** | Every verb that can change anything renders its complete ordered plan and mutates nothing until execution is explicitly requested. |
| <a id="distribution-an-execution-request-may-pin-the-digest-of-the-plan-that-was-read"></a>**An execution request may pin the digest of the plan that was read** | An execution request may pin the digest of the plan that was read; a plan that would now run differently is refused, naming what changed. |
| <a id="distribution-plan-identity-covers-every-input-to-publication"></a>**Plan identity covers every input to publication** | Plan identity covers the repository, the action, the version, the source commit, the resolved release commit, the ordered operations, and the content of the notes — so anything that changes what would be published invalidates the approval. |
| <a id="distribution-step-order-is-part-of-what-the-plan-commits-to"></a>**Step order is part of what the plan commits to** | Step order is part of what the plan commits to: rehearse the upload, push the commit, upload the package, wait for the index to report it, then tag and announce. |
| <a id="distribution-preconditions-that-can-be-evaluated-without-effect-are-evaluated"></a>**Preconditions that can be evaluated without effect are evaluated** | Preconditions that can be evaluated without effect are evaluated while the plan is built, before anything expensive or irreversible begins. |
| <a id="distribution-when-an-installed-parent-owns-the-effects"></a>**When an installed parent owns the effects** | When an installed parent owns the effects, it hands over execution authority keyed to the exact plan, or the run refuses. |
| <a id="distribution-no-release-action-proceeds-from-a-dirty-worktree"></a>**No release action proceeds from a dirty worktree** | No release action proceeds from a dirty worktree, and a bump-and-commit release additionally requires a claimed unit of work and no local commits the board has not recorded. |
| <a id="distribution-the-version-is-bumped-after-the-correctness-gates-and-before-the-artifact-gate"></a>**The version is bumped after the correctness gates and before the artifact gate** | The version is bumped after the correctness gates and before the artifact gate, so a red suite leaves the declared version untouched and the uploaded package is the one that was built and probed. |
| <a id="distribution-the-version-the-bump-produces-must-equal-the-version-the-plan-named"></a>**The version the bump produces must equal the version the plan named** | The version the bump produces must equal the version the plan named, or the run aborts before anything is committed. |
| <a id="distribution-a-named-release-commit-carries-its-own-declared-version"></a>**A named release commit carries its own declared version** | A named release commit carries its own declared version; a requested version that disagrees with it is refused. |
| <a id="distribution-a-version-names-exactly-one-commit"></a>**A version names exactly one commit** | A version names exactly one commit. An existing tag pointing somewhere else refuses rather than being moved. |
| <a id="distribution-publication-builds-from-the-working-tree"></a>**Publication builds from the working tree** | Publication builds from the working tree, so the release commit must be its head; repairing an earlier release runs through the tag-and-announce path, which builds nothing. |
| <a id="distribution-release-evidence-comes-from-an-independently-installed-deployment"></a>**Release evidence comes from an independently installed deployment** | Release evidence comes from an independently installed deployment, never from the candidate tree's own interpreter. |
| <a id="distribution-the-identity-probe-runs-isolated"></a>**The identity probe runs isolated** | The identity probe runs isolated — no inherited module search path, working directory outside the repository — so the installed deployment cannot import the candidate and echo it back. |
| <a id="distribution-a-deployment-running-a-source-checkout-must-be-clean-and-tree-identical-to-the-candidate"></a>**A deployment running a source checkout must be clean and tree-identical to the candidate** | A deployment running a source checkout must be clean and tree-identical to the candidate; one installed from a registry must match by version, file set, and content digest, with the release tag already on the candidate commit. |
| <a id="distribution-a-self-reported-identity-payload-is-structurally-validated-and-its-digest-recomputed-locally-before-it-is-believed"></a>**A self-reported identity payload is structurally validated and its digest recomputed locally before it is believed** | A self-reported identity payload is structurally validated and its digest recomputed locally before it is believed. |
| <a id="distribution-the-artifact-gate-discards-prior-build-output"></a>**The artifact gate discards prior build output** | The artifact gate discards prior build output, then proves the fresh package by installing it into a throwaway environment and exercising its entry points. |
| <a id="distribution-verification-runs-the-publishing-path-s-own-checks-through-the-same-body"></a>**Verification runs the publishing path's own checks through the same body** | Verification runs the publishing path's own checks through the same body. There is no second verification route to drift. |
| <a id="distribution-first-parent-landings-produce-single-entries"></a>**First-parent landings produce single entries** | Only first-parent landings are counted, so one merged unit of work contributes one entry rather than one per internal commit. |
| <a id="distribution-landings-sharing-a-task-identity-collapse-into-one-entry"></a>**Landings sharing a task identity collapse into one entry** | Landings sharing a task identity collapse into one entry, held where that task first landed and described by its latest wording. |
| <a id="distribution-a-revert-pairs-with-the-landing-whose-history-contains-the-reverted-commit"></a>**A revert pairs with the landing whose history contains the reverted commit** | A revert pairs with the landing whose history contains the reverted commit, not with one whose identifier equals it. |
| <a id="distribution-every-entry-carries-at-least-one-reference-back-into-history"></a>**Every entry carries at least one reference back into history** | Every entry carries at least one reference back into history, and entries preserve the order in which the work landed. |
| <a id="distribution-entries-group-by-the-project-each-commit-itself-declares"></a>**Entries group by the project each commit itself declares** | Entries group by the project each commit itself declares; a commit declaring none lands in a general grouping rather than disappearing. |
| <a id="distribution-a-trailing-handle-is-stripped-from-a-description-only-when-it-matches-that-commit-s-own-recorded"></a>**A trailing handle is stripped from a description only when it matches that commit's own recorded** | A trailing handle is stripped from a description only when it matches that commit's own recorded identifier. |
| <a id="distribution-the-window-runs-from-the-highest-versioned-prior-release-tag-reachable-from-the-release-commit"></a>**The window runs from the highest-versioned prior release tag reachable from the release commit** | The window runs from the highest-versioned prior release tag reachable from the release commit, addressed through its fully qualified ref namespace; with no prior tag it degrades to a bounded window of recent landings and says so. |
| <a id="distribution-curation-owns-the-region-above-the-generated-inventory"></a>**Curation owns the region above the generated inventory** | Curation owns the region above the generated inventory; everything from the inventory down is regenerated at publication against the real release commit. |
| <a id="distribution-notes-are-refused-when-they-are-an-untouched-draft"></a>**Notes are refused when they are an untouched draft** | Notes are refused when they are an untouched draft, when they still carry the placeholder, or when the curated region holds nothing but banner and headings. |
| <a id="distribution-credentials-are-obtained-and-validated-before-the-first-externally-visible-action"></a>**Credentials are obtained and validated before the first externally visible action** | Credentials are obtained and validated before the first externally visible action, not at the moment they are used. |
| <a id="distribution-the-irreversible-upload-is-rehearsed-before-publication"></a>**The irreversible upload is rehearsed before publication** | The irreversible upload is rehearsed against the real endpoint in a no-effect mode before it is performed. |
| <a id="distribution-the-release-commit-reaches-the-shared-remote-before-the-package-is-uploaded"></a>**The release commit reaches the shared remote before the package is uploaded** | The release commit reaches the shared remote before the package is uploaded, and the announcement waits until the index actually reports the version — failing loudly if it never does. |
| <a id="distribution-every-publication-step-converges"></a>**Every publication step converges** | Every publication step converges rather than duplicating, so a release interrupted partway through is completed by re-running it. |
| <a id="distribution-an-operator-interruption-terminates-with-a-status-distinct-from-a-gate-failure"></a>**An operator interruption terminates with a status distinct from a gate failure** | An operator interruption terminates with a status distinct from a gate failure. |
| <a id="distribution-what-the-operator-reviews-before-authorizing-an-installation-is-produced-purely-by-observation"></a>**What the operator reviews before authorizing an installation is produced purely by observation** | What the operator reviews before authorizing an installation is produced purely by observation, and is the same resolved plan that later executes. |
| <a id="distribution-an-approval-of-executable-repository-configuration-binds-an-exact-snapshot-of-it"></a>**An approval of executable repository configuration binds an exact snapshot of it** | An approval of executable repository configuration binds an exact snapshot of it; applying refuses when the live configuration differs from what the operator saw. |
| <a id="distribution-approval-is-granted-durably-only-after-every-operation-it-authorized-has-completed"></a>**Approval is granted durably only after every operation it authorized has completed** | Approval is granted durably only after every operation it authorized has completed, never partway through. |
| <a id="distribution-no-change-is-made-until-the-record-describing-it-has-been-formed-and-accepted-as-writable"></a>**No change is made until the record describing it has been formed and accepted as writable** | No change is made until the record describing it has been formed and accepted as writable, and that record is durably committed before the next change is attempted. |
| <a id="distribution-each-record-carries-the-complete-prior-state-of-what-it-touched"></a>**Each record carries the complete prior state of what it touched** | Each record carries the complete prior state of what it touched — the previous value, the previous permissions, and whether the file, setting, or parent directory existed at all. |
| <a id="distribution-prior-state-is-captured-once-at-first-application"></a>**Prior state is captured once, at first application** | Prior state is captured once, at first application; a repeat never re-derives it from state the installation itself produced. |
| <a id="distribution-reversal-runs-the-recorded-operations-in-exact-reverse-order-of-application"></a>**Reversal runs the recorded operations in exact reverse order of application** | Reversal runs the recorded operations in exact reverse order of application, and refuses a record whose order is not the exact inverse. |
| <a id="distribution-reversal-restores-only-what-still-matches-what-was-applied"></a>**Reversal restores only what still matches what was applied** | Reversal restores only what still matches what was applied. Anything since modified, and anything never owned, is left in place and reported as retained. |
| <a id="distribution-a-container-is-removed-only-when-the-installation-created-it-and-it-is-still-empty"></a>**A container is removed only when the installation created it and it is still empty** | A container is removed only when the installation created it and it is still empty. |
| <a id="distribution-a-shared-setting-other-holders-still-depend-on-is-retained"></a>**A shared setting other holders still depend on is retained** | A shared setting other holders still depend on is retained, and the departing holder hands its record of the prior state to a survivor before releasing ownership; a shared prerequisite is retained whenever any dependent setting was. |
| <a id="distribution-anything-an-uninstall-declines-to-remove-is-reported-as-residue"></a>**Anything an uninstall declines to remove is reported as residue** | Anything an uninstall declines to remove is reported as residue, with a durable addressable handle to the record of exactly what remains. |
| <a id="distribution-an-interrupted-reversal-blocks-a-new-installation-until-it-is-resumed-to-completion"></a>**An interrupted reversal blocks a new installation until it is resumed to completion** | An interrupted reversal blocks a new installation until it is resumed to completion, and both directions are resumable and idempotent. |
| <a id="distribution-the-ownership-record-is-discarded-only-after-every-one-of-its-operations-has-a-terminal"></a>**The ownership record is discarded only after every one of its operations has a terminal** | The ownership record is discarded only after every one of its operations has a terminal, recorded outcome. |
| <a id="distribution-the-ownership-history-is-append-only-and-totally-ordered"></a>**The ownership history is append-only and totally ordered** | The ownership history is append-only and totally ordered, every fact self-contained and bounded, written as one indivisible append through a real file that is not followed through a link. |
| <a id="distribution-an-unreadable-truncated-or-inconsistent-history-refuses"></a>**An unreadable, truncated, or inconsistent history refuses** | A history that is unreadable, truncated, or internally inconsistent refuses, rather than being repaired, truncated, or read as evidence that nothing was installed. |
| <a id="distribution-generated-artifacts-live-in-a-directory-the-product-owns"></a>**Generated artifacts live in a directory the product owns** | Generated artifacts live in a directory the product owns and are activated by redirecting the host tool there, never by writing into the location the repository already uses for the same purpose. |
| <a id="distribution-every-generated-artifact-carries-an-ownership-digest"></a>**Every generated artifact carries an ownership digest** | Every generated artifact carries an ownership digest, so an untouched installation is distinguishable from a locally modified one and from a newer generated shape. |
| <a id="distribution-when-a-setting-s-prior-scoped-value-differs-from-the-value-that-was-actually-taking-effect"></a>**When a setting's prior scoped value differs from the value that was actually taking effect** | When a setting's prior scoped value differs from the value that was actually taking effect, the preview shows both. |

## Conduct

| Label | Invariant |
| --- | --- |
| <a id="conduct-a-refusal-that-can-name-a-way-out-leads-with-the-runnable-command"></a>**A refusal that can name a way out leads with the runnable command** | A refusal that can name a way out leads with the runnable command, then the diagnostic. |
| <a id="conduct-repair-first-refusal-exemptions"></a>**Repair-first refusal exemptions** | Two exemptions: a refusal with nothing to run stays a bare diagnostic; a refusal about the invocation stays one contract statement. |
| <a id="conduct-gate-reports-are-a-third-shape"></a>**Gate reports are a third shape** | Gate reports are a third shape — the finding board is evidence, then a summary. |
| <a id="conduct-absence-of-evidence-is-not-evidence-of-absence"></a>**Absence of evidence is not evidence of absence** | Absence of evidence is not evidence of absence. |
| <a id="conduct-every-degradation-is-loud"></a>**Every degradation is loud** | Every degradation is loud; silent success and silent degradation do not look alike. One exemption: a decoration laid over another operation — speech, the working-state meter — fails silently, precisely so that it can never alter the thing it decorates. |
| <a id="conduct-prefer-the-good-property-never-block-on-it"></a>**Prefer the good property, never block on it** | Prefer the good property, never block on it: cross-review, launch advance, rewriting, and adjudication are each attempted and none is required. |
| <a id="conduct-one-visible-path"></a>**One visible path** | One visible path — no shims, aliases, fallbacks, or legacy branches; durable data gets one forward migration. |
| <a id="conduct-the-agent-is-a-user-with-its-own-surface"></a>**The agent is a user with its own surface** | The agent is a user with its own surface, and its tone is a stated requirement: capability, not restriction. |
| <a id="conduct-observation-initializes-nothing"></a>**Observation initializes nothing** | Observation initializes nothing — no repository, worktree, team state, claim, hook, or steering. |
| <a id="conduct-each-capability-tier-is-independently-usable"></a>**Each capability tier is independently usable** | Each capability tier is independently usable; a user may stop at any rung. |
| <a id="conduct-unknown-is-not-the-same-as-clear"></a>**Unknown is not the same as clear** | Unknown is not the same as clear. A check that could not run does not report what a check that ran and found nothing reports. |

## The properties most worth guarding

Ranked by how quietly they fail rather than by importance.

- **[The identity probe runs isolated](#distribution-the-identity-probe-runs-isolated)** — an identity probe that inherits the candidate's module path makes
   the installed deployment import the candidate. The gate then passes forever,
   and it passes for the one reason that makes it worthless.
- **[Only the lifecycle authority transitions an agent](lifecycle.md#lifecycle-only-the-lifecycle-authority-transitions-an-agent)** — rendering must not launch. A refresh becoming a launch storm is
   invisible until it is expensive.
- **[A card whose position did not change receives no style write](lifecycle.md#surface-a-card-whose-position-did-not-change-receives-no-style-write) / [A card's column and span are decided once](lifecycle.md#surface-a-card-s-column-and-span-are-decided-once)** — zero-write and latched columns. Both look correct in a
   screenshot and fail only under concurrency.
- **[Prior state is captured once, at first application](#distribution-prior-state-is-captured-once-at-first-application)** — prior state re-derived on a repeat install records the
   installer's own output as what was there before. Nothing is wrong until the
   uninstall, which then restores the wrong thing.
- **[Self-authored review is ranked last, never excluded](identity.md#work-self-authored-review-is-ranked-last-never-excluded)** — review preference implemented as a hard refusal starves the review
   phase whenever peers are busy.
- **[Each authority carries its own freshness counter](identity.md#identity-each-authority-carries-its-own-freshness-counter)** — a global revision instead of per-authority freshness is correct
   until two channels interleave.
- **[A failed enumeration is not evidence of absence](lifecycle.md#topology-a-failed-enumeration-is-not-evidence-of-absence) / [Absence of evidence is not evidence of absence](#conduct-absence-of-evidence-is-not-evidence-of-absence)** — an empty enumeration read as absence destroys state on a
   transient error.
- **[A fact whose classification disagrees with the evidence backing it aborts the projection](session.md#session-a-fact-whose-classification-disagrees-with-the-evidence-backing-it-aborts-the-projection)** — a projection that degrades instead of aborting produces a record
   indistinguishable from a good one, and everything downstream inherits it.
- **[A deferred render does not commit its fingerprint](lifecycle.md#surface-a-deferred-render-does-not-commit-its-fingerprint)** — a deferred render that commits its fingerprint leaves a
   permanently blank surface with no error.

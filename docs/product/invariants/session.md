# Invariant register — Session, metrics, and extension

[Invariant register](../invariants.md) · [Spice product model](../README.md)
## Session

| Label | Invariant |
| --- | --- |
| <a id="session-the-briefing-answers-four-questions-mechanically"></a>**The briefing answers four questions mechanically** | The briefing answers four questions mechanically: what was asked, what was last delivered, what the working set was, what steering is pending. |
| <a id="session-asks-are-sourced-from-the-steering-plane"></a>**Asks are sourced from the steering plane** | Asks are sourced from the steering plane; transcript prose is secondary. |
| <a id="session-recovery-shows-the-recovered-ask"></a>**Recovery shows the recovered ask** | Recovery shows the recovered ask rather than continuation boilerplate, and never renders assistant text as the user's ask. |
| <a id="session-sections-with-nothing-to-say-are-omitted"></a>**Sections with nothing to say are omitted** | Sections with nothing to say are omitted rather than emitting a mantra. |
| <a id="session-rehydration-is-bounded-to-a-small-number-of-recent-compaction-windows"></a>**Rehydration is bounded to a small number of recent compaction windows** | Rehydration is bounded to a small number of recent compaction windows. |
| <a id="session-identical-entries-collapse-and-no-class-repeats-back-to-back"></a>**Identical entries collapse and no class repeats back-to-back** | Identical entries collapse and no class repeats back-to-back. |
| <a id="session-windows-the-engine-could-not-read-are-reported-loudly"></a>**Windows the engine could not read are reported loudly** | Windows the engine could not read are reported loudly, not silently skipped. |
| <a id="session-learnings-are-distilled-at-task-completion-and-held-in-a-bounded-store"></a>**Learnings are distilled at task completion and held in a bounded store** | Learnings are distilled at task completion and held in a bounded store. |
| <a id="session-the-working-state-line-is-short-high-signal"></a>**The working-state line is short, high-signal** | The working-state line is short, high-signal, repeat-suppressed, and reflects actual state. |
| <a id="session-message-shape-classification-is-deterministic-and-structural"></a>**Message-shape classification is deterministic and structural** | Message-shape classification is deterministic and structural, not a prefix sniff. |
| <a id="session-judge-and-maxim-scanning-exclude-generated-diff"></a>**Judge and maxim scanning exclude generated diff** | Judge and maxim scanning exclude generated diff, patch, and tool-output bodies. |
| <a id="session-at-most-one-maxim-reminder-per-content-derived-key-per-compaction-epoch"></a>**At most one maxim reminder per content-derived key per compaction epoch** | At most one maxim reminder per content-derived key per compaction epoch; self-echo suppressed. |
| <a id="session-a-confirmed-maxim-reminder-returns-as-ordinary-steering"></a>**A confirmed maxim reminder returns as ordinary steering** | A confirmed maxim reminder returns as ordinary steering; the counsel has no private channel. |
| <a id="session-adjudication-is-optional"></a>**Adjudication is optional** | Adjudication is optional; without a judge the trigger publishes directly. |
| <a id="session-new-taste-is-mined-from-recurring-corrections-and-filed-as-a-proposal"></a>**New taste is mined from recurring corrections and filed as a proposal** | New taste is mined from recurring corrections and filed as a proposal, not invented. |
| <a id="session-the-transcript-supplies-what-happened"></a>**The transcript supplies what happened** | The transcript supplies what happened — deliveries, commits, commands, touched paths, boundaries. It never supplies what is being asked. |
| <a id="session-a-directive-whose-time-cannot-be-derived-from-its-own-identity-is-dropped"></a>**A directive whose time cannot be derived from its own identity is dropped** | A directive whose time cannot be derived from its own identity is dropped rather than given a substitute timestamp. |
| <a id="session-a-directive-is-shown-only-for-the-thread-being-briefed"></a>**A directive is shown only for the thread being briefed** | A directive is shown only for the thread being briefed, and always carries the key needed to answer it. |
| <a id="session-the-briefing-declares-what-set-its-window"></a>**The briefing declares what set its window** | The briefing declares what set its window, where the window starts, and how many boundaries were requested versus selected — naming session start when no boundary exists. |
| <a id="session-recency-is-measured-against-the-newest-activity-actually-observed-in-the-material"></a>**Recency is measured against the newest activity actually observed in the material** | Recency is measured against the newest activity actually observed in the material, not against wall-clock now. |
| <a id="session-when-several-bounds-apply-to-one-selection-the-narrowest-wins"></a>**When several bounds apply to one selection the narrowest wins** | When several bounds apply to one selection the narrowest wins, and a request above the ceiling is served up to it and says the ceiling is why it stopped. |
| <a id="session-each-class-of-evidence-is-ordered-by-one-declared-rule"></a>**Each class of evidence is ordered by one declared rule** | Each class of evidence is ordered by one declared rule, so identical inputs always produce identical order. |
| <a id="session-unanswered-and-refused-directives-outrank-acknowledged-ones-of-the-same-recency"></a>**Unanswered and refused directives outrank acknowledged ones of the same recency** | Unanswered and refused directives outrank acknowledged ones of the same recency, and turns that produced failures outrank newer clean turns. |
| <a id="session-the-task-the-actor-holds-outranks-every-other-board-row"></a>**The task the actor holds outranks every other board row** | The task the actor holds outranks every other board row; only the actor's own claim is enumerated, and peers' active work is reported as a count. |
| <a id="session-sections-carrying-evidence-are-omitted-when-they-have-no-rows"></a>**Sections carrying evidence are omitted when they have no rows** | Sections carrying evidence are omitted when they have no rows; sections establishing what was examined are emitted even when everything in them is zero. |
| <a id="session-any-list-shortened-by-a-limit-reports-how-many-rows-were-withheld"></a>**Any list shortened by a limit reports how many rows were withheld** | Any list shortened by a limit reports how many rows were withheld, and any pruning is announced together with the original size — the notice itself charged against the budget. |
| <a id="session-sections-are-emitted-in-decision-priority-order"></a>**Sections are emitted in decision-priority order** | Sections are emitted in decision-priority order, because the budget truncates from the end. |
| <a id="session-absent-facts-render-as-explicit-unknowns-distinct-from-zero"></a>**Absent facts render as explicit unknowns distinct from zero** | Absent facts render as explicit unknowns distinct from zero, and a scan that failed reports unknown severity carrying its error rather than clean. |
| <a id="session-every-external-probe-is-time-bounded-and-no-single-unavailable-subsystem-prevents-a-briefing-from-being-produced"></a>**Every external probe is time-bounded, and no single unavailable subsystem prevents a briefing from being produced** | Every external probe is time-bounded, and no single unavailable subsystem prevents a briefing from being produced. |
| <a id="session-windows-tile-the-examined-span-contiguously-through-the-present"></a>**Windows tile the examined span contiguously through the present** | Windows tile the examined span contiguously through the present, so no activity falls outside every window; a session that never compacted still yields exactly one window, labelled with why it has no internal boundaries. |
| <a id="session-an-exchange-straddling-a-boundary-belongs-to-both-adjacent-windows"></a>**An exchange straddling a boundary belongs to both adjacent windows** | An exchange straddling a boundary belongs to both adjacent windows, and only a compaction that actually severed context counts as a boundary. |
| <a id="session-material-read-only-to-establish-what-preceded-a-window-s-start-is-excluded-from-its-contents"></a>**Material read only to establish what preceded a window's start is excluded from its contents** | Material read only to establish what preceded a window's start is excluded from its contents, so a window holds the same records however much surrounding material was consulted. |
| <a id="session-boundary-discovery-reads-backward-from-the-end-and-stops-as-soon-as-enough-are-found"></a>**Boundary discovery reads backward from the end and stops as soon as enough are found** | Boundary discovery reads backward from the end and stops as soon as enough are found, so recovery cost scales with the window requested rather than with session length. |
| <a id="session-the-unit-of-the-record-is-one-operator-ask"></a>**The unit of the record is one operator ask** | The unit of the record is one operator ask; every observed activity is attributed to the ask open when it occurred, and activity before any ask opens a record of its own. |
| <a id="session-an-exchange-is-complete-only-when-the-transcript-says-it-ended"></a>**An exchange is complete only when the transcript says it ended** | An exchange is complete only when the transcript says it ended; otherwise it stays open, its extent taken from its last observed activity, and a window holding one is itself open. |
| <a id="session-records-merged-from-several-transcripts-order-by-time-with-source-identity-breaking-ties"></a>**Records merged from several transcripts order by time with source identity breaking ties** | Records merged from several transcripts order by time with source identity breaking ties, and the differing timestamp spellings of different drivers compare as the same instant. |
| <a id="session-recorded-text-is-exactly-what-the-transcript-held"></a>**Recorded text is exactly what the transcript held** | Recorded text is exactly what the transcript held; only explicitly derived fields are reformatted, and a display echo is not a second occurrence. |
| <a id="session-a-fact-whose-classification-disagrees-with-the-evidence-backing-it-aborts-the-projection"></a>**A fact whose classification disagrees with the evidence backing it aborts the projection** | A fact whose classification disagrees with the evidence backing it aborts the projection rather than producing a degraded record. |
| <a id="session-an-invocation-and-its-outcome-are-separate-facts"></a>**An invocation and its outcome are separate facts** | An invocation and its outcome are separate facts: a command whose outcome was never observed is neither successful nor failed, and an outcome attaches to the invocation it names. |
| <a id="session-a-filter-the-material-can-never-satisfy-is-refused-with-the-workable-alternatives-named"></a>**A filter the material can never satisfy is refused with the workable alternatives named** | A filter the material can never satisfy is refused with the workable alternatives named, rather than answered with an empty result. |
| <a id="session-resolution-is-loud"></a>**Resolution is loud** | Resolution is loud: an input that resolves to nothing names every unresolvable input at once, and a transcript named twice contributes once. |
| <a id="session-an-agent-identity-is-current-only-while-present-in-the-running-environment"></a>**An agent identity is current only while present in the running environment** | An agent identity counts as current only while it is present in the running process's environment, never when it is merely persisted in the tree from an earlier session. |
| <a id="session-the-meter-announces-change"></a>**The meter announces change** | The meter announces change: what was last shown survives process exit, an expiring claim's urgency tier is part of that identity, and a missing or unusable record makes it speak rather than stay silent. |
| <a id="session-claim-expiry-is-the-only-thing-the-meter-repeats-on-a-timer"></a>**Claim expiry is the only thing the meter repeats on a timer** | Claim expiry is the only thing the meter repeats on a timer, and the interval shortens as expiry approaches. |
| <a id="session-failing-to-collect-the-meter-s-working-state-degrades-to-silence"></a>**Failing to collect the meter's working state degrades to silence** | Failing to collect the meter's working state degrades to silence and never changes the outcome of the command being decorated. |
| <a id="session-a-record-whose-timestamp-cannot-be-normalized-is-dropped-from-time-ordered-reporting"></a>**A record whose timestamp cannot be normalized is dropped from time-ordered reporting** | A record whose timestamp cannot be normalized is dropped from time-ordered reporting rather than given a substitute, and an unknown context window stays unknown rather than defaulting to a nominal size. |
| <a id="session-a-reporting-window-with-no-surviving-source-is-marked-incomplete"></a>**A reporting window with no surviving source is marked incomplete** | A reporting window with no surviving source is marked incomplete rather than reported as zero effort. |
| <a id="session-learnings-are-harvested-only-from-the-span-between-claim-and-completion"></a>**Learnings are harvested only from the span between claim and completion** | Learnings are harvested only from the span between claim and completion, carry the task, slice, and excerpt they came from, and a missing or out-of-order span yields nothing. |
| <a id="session-no-candidate-becomes-durable-without-an-independent-judgment-that-it-is-reusable-and-repository-general"></a>**No candidate becomes durable without an independent judgment that it is reusable and repository-general** | No candidate becomes durable without an independent judgment that it is reusable and repository-general; any failure of that judgment skips the candidate, and skips are reported with their reason. |
| <a id="session-re-observing-a-stored-learning-refreshes-its-recency-and-confirmation-count"></a>**Re-observing a stored learning refreshes its recency and confirmation count** | Re-observing a stored learning refreshes its recency and confirmation count while keeping the original wording and provenance; overflow evicts the least recently confirmed first. |
| <a id="session-the-learning-store-is-replaced-atomically-as-a-whole"></a>**The learning store is replaced atomically as a whole** | The learning store is replaced atomically as a whole, and a record that cannot be parsed stops the load loudly rather than being skipped. |
| <a id="session-distillation-is-bounded-in-what-it-reads-and-what-it-emits"></a>**Distillation is bounded in what it reads and what it emits** | Distillation is bounded in what it reads and what it emits, and never turns a completed task into a failure. |
| <a id="session-an-interactive-render-carries-an-end-to-end-budget-covering-discovery-as-well-as-rendering"></a>**An interactive render carries an end-to-end budget covering discovery as well as rendering** | An interactive render carries an end-to-end budget covering discovery as well as rendering; exceeding it fails naming the action, the inputs, and the budget rather than emitting a partial render as though it were complete. |
| <a id="session-a-phase-boundary-requires-a-long-idle-gap-or-an-activity-change-that-persists-on-both"></a>**A phase boundary requires a long idle gap or an activity change that persists on both** | A phase boundary requires a long idle gap or an activity change that persists on both sides of it, so a single deviating turn never starts a phase. |
| <a id="session-a-maxim-bag-is-one-opinion-with-several-triggers"></a>**A maxim bag is one opinion with several triggers** | A maxim bag is one opinion with several triggers. Matching is over whole words with no stemming, so a bag enumerates its own variations and the matcher never mutates prose to find a hit. |
| <a id="session-a-trigger-must-be-an-alphabetic-word-or-phrase-and-is-refused-at-load-otherwise"></a>**A trigger must be an alphabetic word or phrase and is refused at load otherwise** | A trigger must be an alphabetic word or phrase and is refused at load otherwise; a trigger that can never match a word is a silently dead opinion. |
| <a id="session-one-statement-fires-a-bag-at-most-once-however-many-of-its-triggers-hit"></a>**One statement fires a bag at most once however many of its triggers hit** | One statement fires a bag at most once however many of its triggers hit, and results order by declared bag order then trigger, so the same prose always produces the same reminders in the same sequence. |
| <a id="session-bag-applicability-uses-the-one-shared-selector-grammar"></a>**Bag applicability uses the one shared selector grammar** | Bag applicability uses the one shared selector grammar, and a bag is disabled by name in a tracked record, so every clone sees the same opinions in force and every disablement is enumerable. |
| <a id="session-adjudication-states-the-question-in-several-equivalent-framings-and-shuffles-them"></a>**Adjudication states the question in several equivalent framings and shuffles them** | Adjudication states the question in several equivalent framings and shuffles them, so a judge that latches onto position cannot bias the answer; a reply that does not collapse to yes or no is retried a bounded number of times and then abandoned rather than interpreted. |

| Label | Invariant |

| <a id="metrics-counting-reads-public-typed-transcript-facts"></a>**Counting reads public typed transcript facts** | Counting reads public typed transcript facts, never a second private parse. |
| <a id="metrics-one-line-carrying-prose-reasoning-and-a-tool-call-contributes-all-three"></a>**One line carrying prose, reasoning, and a tool call contributes all three** | One line carrying prose, reasoning, and a tool call contributes all three. |

## Extension, wire, and configuration

| Label | Invariant |
| --- | --- |

| <a id="extension-payloads-are-validated-at-their-emitters"></a>**Payloads are validated at their emitters** | Payloads are validated at their emitters, not only at their readers. |
| <a id="extension-an-answer-with-two-shapes-is-two-types"></a>**An answer with two shapes is two types** | An answer with two shapes is two types, discriminated on meaning, so a reader cannot take a field off the arm that never carried it. |
| <a id="extension-a-field-one-arm-never-carries-is-declared-absent"></a>**A field one arm never carries is declared absent** | A field one arm never carries is declared absent so the reader may narrow on it. |

| <a id="extension-built-in-verbs-and-registered-actions-win-at-every-depth"></a>**Built-in verbs and registered actions win at every depth** | Built-in verbs and registered actions win at every depth; a shadowing mount fails loudly. |
| <a id="extension-a-new-driver-wrapper-or-study-is-a-declared-value"></a>**A new driver, wrapper, or study is a declared value** | A new driver, wrapper, or study is a declared value, not a patch to a dispatcher. |
| <a id="extension-driver-resolution-is-explicit"></a>**Driver resolution is explicit** | Driver resolution is explicit: environment, then configured driver, then a default for unbound worktrees. |
| <a id="extension-every-effective-configuration-value-carries-its-source-provenance"></a>**Every effective configuration value carries its source provenance** | Every effective configuration value carries its source provenance. |
| <a id="extension-bad-configuration-fails-loudly"></a>**Bad configuration fails loudly** | Bad configuration fails loudly. |
| <a id="extension-applicability-is-expressed-once-in-one-selector-grammar-reused-by-policies"></a>**Applicability is expressed once in one selector grammar reused by policies** | Applicability is expressed once in one selector grammar reused by policies, studies, maxims, and hooks. |
| <a id="extension-the-command-optimizer-is-optional"></a>**The command optimizer is optional** | The command optimizer is optional; an unusable one degrades to native execution and reports health without blocking. |
